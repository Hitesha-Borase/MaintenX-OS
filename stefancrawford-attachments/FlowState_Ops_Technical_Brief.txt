Core operating chain

This brief supplements the existing FlowState Ops Full Developer Rebuild Scope. It defines the architecture and discovery decisions Kiaan Tech must document before implementation continues.



1. Required Outcome and Boundaries

FlowState Ops is a food-manufacturing-first operating platform combining ERP, APS, MRP, MES, QMS, WMS, CMMS, traceability, labour, costing, continuous improvement and governed AI. Each module must use a shared relational data model and shared transaction history.

1.1 Non-negotiable principles

One canonical source of truth for every major business object and KPI.

API-first backend; critical business logic must execute server-side.

Strict tenant isolation by company and plant, with authorized master-owner visibility.

Every critical transaction must record company, plant, department, line, order, batch/lot, equipment, user and timestamp where applicable.

Finished goods must not become available or shippable until the required QA release succeeds.

No hardcoded KPIs, demo metrics or UI-only workflows in production.

Food-safety decisions, root-cause approval and release decisions remain human-controlled.

The owner receives source code, database schema, API specification, deployment configuration and technical documentation.

1.2 Delivery strategy

The complete architecture must be defined now, but implementation should be milestone-based. Kiaan Tech must first complete discovery, the current-system gap assessment and hardware survey. No machine connection should be quoted as confirmed until PLC/controller access and protocol support are verified.

Operations

ARCHITECTURE RULE: The software must never connect a cloud service directly to an unsegmented machine-control network. Machine data should pass through a controlled OT/IT boundary and approved edge gateway. Initial connections should be read-only unless a separate safety and change-control review approves writing commands.

7.2 Recommended connectivity pattern

Machine PLC/controller exposes approved read-only tags using its native industrial protocol.

A protocol adapter or industrial edge gateway reads the machine on the local OT network.

The gateway timestamps, normalizes and temporarily buffers data if the internet or application is unavailable.

The gateway publishes events securely to the FlowState integration API or MQTT broker using outbound TLS.

FlowState maps the machine event to tenant, plant, line, asset, production order, SKU, batch, shift and operator context.

Validated events update live production, downtime, OEE, H/B, maintenance history and alerts.

Operators classify unrecognized stops or correct context through an audited workflow; raw events remain unchanged.

10. End-to-End Data Flow

Sales order or forecast creates demand by customer, SKU, quantity and required ship date.

APS calculates a capacity-constrained plan using materials, labour, equipment, QA, smokehouse/drying, packaging and shipping constraints.

MRP explodes the approved BOM and reserves available raw-material and packaging lots.

A released production order creates the digital batch record, job instructions, labour plan and required quality checks.

Operator actions and approved machine events record actual start/stop time, output, downtime, speed, personnel, equipment and material consumption.

Quality checks apply pass/fail rules. A critical failure creates a deviation/hold and blocks finished-goods availability.

Authorized QA release creates the finished-goods lot and inventory receipt.

Warehouse allocates, picks and ships only released inventory using FEFO where required.

Batch 360 traces customer shipment back to every contributing material lot and forward from supplier lot to affected customers.

The same governed events calculate H/B, OEE, schedule attainment, yield, labour, cost, reliability and executive risk without duplicate calculations.

11. Security, SaaS and Data Governance

Strict company/tenant isolation using server-side authorization and tenant-scoped database controls; hiding menus is insufficient.

Master-owner view may span companies only for explicitly authorized administrative and portfolio functions.

Role, plant, department, line and action-level permissions; least-privilege defaults.

MFA support, secure password reset, session controls, secrets management and access review.

Immutable audit events and electronic signatures for controlled approvals and corrections.

Encryption in transit and at rest, backup/restore testing, disaster recovery and defined retention policies.

Development, staging and production separation; sanitized test data; no production credentials in code.

Data export/portability by tenant and a documented offboarding process.

Canadian privacy/data-residency requirements and the target hosting region must be agreed before production deployment.

12. AI and Meeting Intelligence Guardrails

AI may summarize records, identify contradictions, suggest hypotheses, draft actions and retrieve verified solutions.

AI must cite the internal records used and label facts, calculations, hypotheses and recommendations separately.

AI must not invent missing evidence, independently confirm a root cause, release product, close CAPA or alter critical records.

Every AI-created proposed action must require an authorized human review before it writes to operational records.

Core production, quality, inventory and maintenance workflows must continue when the AI service is unavailable.

Prompt, model, source, output, reviewer and disposition should be logged for governed AI actions.

17. Definition of Done and Acceptance

COMPLETION STANDARD: A page, chart, table, API endpoint or database table is not a completed feature. A feature is complete only when its workflow, database transaction, calculations, permissions, audit trail, error handling, reporting, tests and documentation work end to end.



No critical workflow uses static/demo data or front-end-only validation.

A failed critical quality check automatically creates a hold and prevents finished-goods release and shipment.

The same production event correctly updates materials, batch history, labour, quality, inventory, traceability, cost and KPIs.

H/B and OEE results reconcile from the underlying event data for daily, weekly, monthly, YTD and annual views.

Machine data can be traced from raw reading through normalized event, transaction, KPI and displayed result.

Tenant-isolation, authorization, migration, backup/restore and rollback tests pass before production cutover.

FlowState Ops receives all source, credentials, schemas, specifications, configuration and documentation.
