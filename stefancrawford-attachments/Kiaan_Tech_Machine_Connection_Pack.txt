1. Integration Standard

Phase 1 is read-only monitoring and data collection.

No remote start/stop, recipe download, setpoint write or safety interaction.

Existing control networks and cables must be documented before changes.

Raw readings must be timestamped, buffered, auditable and linked to the FlowState asset, job, batch and shift.

Critical quality, release and food-safety decisions remain human-approved.

1.1 Target data flow

Machine controller → approved read interface → industrial edge gateway → outbound encrypted connection → FlowState integration API/MQTT → validation and normalization → production, downtime, OEE, H/B and maintenance records.

4. Required Network and Security Design

Provide an OT/IT network drawing for each machine, including every controller, HMI, switch, gateway and IP address.

Use a segmented OT VLAN and firewall rules approved by plant IT.

Prefer outbound TLS from the gateway; prohibit direct inbound internet exposure.

Use unique credentials, least privilege, certificate rotation, patch ownership and logged remote support.

Buffer readings locally during outages and safely replay without duplicates.

Synchronize controller, gateway and platform time to an approved time source.

Provide a rollback plan and prove that loss of FlowState cannot stop or alter the machine.
